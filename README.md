One line, at most 120 characters, the funniest weather forecast for a city that does not exist. `main.py` writes the line deterministically to `/output/entry.txt`:

> Forecast for Bumbershoot: rain falls up today, so umbrellas are worn as hats and hats as umbrellas.

Bumbershoot is an invented city — named after the umbrella, because in Bumbershoot the rain falls up and the umbrella has to be worn as a hat. The line borrows the flat phrasing of an official weather bulletin and then breaks it.

## Run it

```sh
python3 main.py
```
